# CS 305 Software Security Portfolio

## Project Overview

For this course, I worked with Artemis Financial, a financial consulting company that helps customers with financial planning and services. The company wanted to improve the security of its existing software application to better protect sensitive customer information. My responsibility was to identify potential security vulnerabilities and recommend ways to make the application more secure.

Throughout this project, I worked on identifying security risks, implementing secure coding practices, and making sure the application could securely communicate and protect data.

## Reflection

### 1. What did you do well when identifying software security vulnerabilities? Why is secure coding important?

I think I did well identifying possible security vulnerabilities and understanding how they could affect the application. I focused on reviewing the existing software and looking for areas where security could be improved. Secure coding is important because it helps prevent unauthorized access, data breaches, and other security problems. For a financial company like Artemis Financial, protecting customer information is extremely important. Having strong software security also helps build customer trust and protects the company's reputation.

### 2. Which part of the vulnerability assessment was challenging or helpful?

One of the more challenging parts of the project was understanding the vulnerabilities identified through the dependency-check process. Some of the results required additional research to understand what the vulnerabilities meant and how serious they could be. I found this helpful because it gave me more experience working with security tools and understanding how third-party dependencies can introduce risks into an application.

### 3. How did you increase layers of security? What would you use in the future?

I improved the application's security by implementing HTTPS and SSL/TLS to help protect information being transmitted between the application and its users. I also worked with hashing algorithms to demonstrate how data integrity can be verified. These security measures help protect information and reduce potential security risks.

In the future, I would continue using dependency-check tools, vulnerability scanners, and secure coding guidelines to identify security problems. I would also reference industry standards such as OWASP when deciding which security improvements would be the most effective.

### 4. How did you make sure the application was functional and secure?

After making changes to the application, I tested it to make sure everything was still working correctly. I used Maven to build and run the application and checked that the security features were functioning as expected. I also used dependency-check scanning to review possible vulnerabilities in the project. Testing after making changes is important because even a small update can introduce new issues. I wanted to make sure the application was still functional while also improving its security.

### 5. What resources, tools, or coding practices were helpful?

Some of the tools I found helpful throughout this project were Maven, the OWASP Dependency-Check plugin, Java security libraries, and SSL/TLS certificates. These tools helped me understand how to identify security vulnerabilities and implement additional security measures.

I also learned the importance of keeping dependencies updated, reviewing security reports, and testing code after changes are made. These are practices I plan to continue using in future software development projects.

### 6. What would you show future employers from this assignment?

I would show future employers my Artemis Financial security report and the work I completed to improve the application's security. I think this project demonstrates that I understand the importance of secure coding and can use different tools to identify potential vulnerabilities.

It also shows that I have experience working with Java applications, reviewing dependencies, and implementing security measures like HTTPS. These are skills that I believe will be useful as I continue working toward a career in software development.

## Conclusion

Overall, this project helped me better understand how important security is throughout the software development process. Before this course, I had some understanding of software security, but this project gave me more hands-on experience identifying vulnerabilities and applying security improvements. I learned that security should be considered throughout development instead of being something that is only checked at the end.

This experience will be useful in future projects because I have a better understanding of how to create software that is both functional and secure.
